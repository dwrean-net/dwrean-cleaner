# dwrean Cleaner Portable — v1.0.0 v0.2 beta

Δωρεάν, portable εφαρμογή **του Κυριάκου Οικονομίδη (dwrean.net)** για Windows 10/11 (64-bit), με ελληνικό περιβάλλον και **ένα κουμπί** για καθαρισμό *παλιών* προσωρινών αρχείων και περιορισμένων caches. Δεν απαιτεί εγκατάσταση ή δικαιώματα διαχειριστή.

## Λήψη και χρήση

Κατέβασε το `dwrean-cleaner-portable.exe` από [Releases](../../releases/latest), άνοιξέ το και πάτησε **ΚΑΘΑΡΙΣΜΟΣ ΤΩΡΑ**. Θα εμφανιστούν ο αριθμός των αρχείων που αφαιρέθηκαν και ο χώρος που απελευθερώθηκε. Αν κάποιος browser είναι ανοιχτός, η cache του παραλείπεται.

## Τι νέο υπάρχει στην πρώτη ολοκληρωμένη έκδοση

- Το επίσημο **εικονίδιο του dwrean.net** εμφανίζεται στο παράθυρο και ενσωματώνεται στο εκτελέσιμο αρχείο. Η κατασκευή το αντλεί από το favicon του dwrean.net ή από το επίσημο λογότυπο του εκδότη στο [dwrean-radio](https://github.com/dwrean-net/dwrean-radio).
- Το κουμπί **«Περί»** δείχνει τον δημιουργό, την έκδοση, την άδεια MIT και ενεργούς συνδέσμους προς dwrean.net και GitHub.
- Το αρχείο .exe διαθέτει πληροφορίες προϊόντος, εκδότη και έκδοσης στις Ιδιότητες των Windows.
- Βελτιωμένη διάταξη και εμφανής ένδειξη **v1.0.0**, διατηρώντας τον καθαρισμό με ένα κουμπί.

## Τι καθαρίζει

Από συγκεκριμένους υποφακέλους του `AppData\Local` του τρέχοντος χρήστη, μόνο αρχεία παλαιότερα από:

| Κατηγορία | Διαδρομή κάτω από `AppData\Local` | Ελάχιστη ηλικία |
| --- | --- | --- |
| Προσωρινά | `Temp` | 14 ημέρες |
| DirectX shaders | `D3DSCache` | 14 ημέρες |
| Παλιά dumps | `CrashDumps` | 30 ημέρες |
| Αναφορές σφαλμάτων | `Microsoft\Windows\WER\ReportArchive` | 30 ημέρες |
| Αναφορές σε αναμονή | `Microsoft\Windows\WER\ReportQueue` | 45 ημέρες |
| Προσωρινά αναφορών σφαλμάτων | `Microsoft\Windows\WER\Temp` | 14 ημέρες |
| NVIDIA graphics caches | `NVIDIA\DXCache`, `NVIDIA\GLCache` | 30 ημέρες |
| AMD graphics caches | `AMD\DxCache`, `AMD\GLCache` | 30 ημέρες |
| Chrome, Edge, Brave | Μόνο `Cache\Cache_Data`, `Code Cache\js`, `Code Cache\wasm`, `GPUCache`, `GrShaderCache`, `ShaderCache` των αναγνωρισμένων προφίλ | 30 ημέρες |
| Firefox | Μόνο `Mozilla\Firefox\Profiles\<profile>\cache2\entries` | 30 ημέρες |

Η ηλικία προκύπτει από την τελευταία τροποποίηση του αρχείου. Οι caches του browser **δεν καθαρίζονται αν ο browser είναι ανοιχτός**. Οι caches μπορεί να ξαναδημιουργηθούν ή να απαιτήσουν επαναφόρτωση δεδομένων στο επόμενο άνοιγμα.

**Δεν αγγίζει** Λήψεις, Έγγραφα, φωτογραφίες, Επιφάνεια εργασίας, Κάδο Ανακύκλωσης, cookies, ιστορικό, κωδικούς, αποθηκευμένα sessions, σελιδοδείκτες, Registry, εγκατεστημένα προγράμματα, Windows Update και αρχεία συστήματος.

Το πρόγραμμα αποφεύγει symbolic links/junctions, δεν διαγράφει φακέλους, και παραλείπει όσα αρχεία είναι κλειδωμένα ή μη προσβάσιμα. Ελέγχει τα δικαιώματα και την ηλικία κάθε αρχείου πριν προσπαθήσει να το αφαιρέσει. Μπορεί να χρειάζεται αρκετός χρόνος σε πολλούς μικρούς φακέλους.

**Προσοχή:** Οι διαγραφές γίνονται οριστικά, χωρίς μεταφορά στον Κάδο. Τα παλιά dumps/αναφορές ενδέχεται να είναι χρήσιμα για διάγνωση προβλημάτων. Η εφαρμογή δεν εγγυάται επιτάχυνση ή συγκεκριμένη εξοικονόμηση χώρου και δεν αντικαθιστά το Windows Storage Sense/Εκκαθάριση δίσκου.

## Build από τον πηγαίο κώδικα

Χρειάζεται Go 1.22 ή νεότερο (χωρίς εξωτερικές εξαρτήσεις):

```powershell
go test ./...
go build -trimpath -ldflags="-s -w -H windowsgui" -o dwrean-cleaner-portable.exe .
```

Το GitHub Actions workflow δοκιμάζει τον κώδικα σε Linux και Windows, χτίζει το `exe` και δημοσιεύει δοκιμαστικό Release μαζί με ZIP και SHA-256 checksum.

Το εκτελέσιμο **δεν έχει ψηφιακή υπογραφή** και μπορεί να εμφανίσει ειδοποίηση SmartScreen. Απαιτείται χειροκίνητη δοκιμή σε πραγματικά Windows πριν από ευρεία διανομή.
