# dwrean Cleaner Portable

Δωρεάν, portable καθαρισμός παλιών προσωρινών αρχείων για Windows 10/11 (64-bit) με **ένα κουμπί** και ελληνικό περιβάλλον.

## Λήψη και χρήση

Κατέβασε το `dwrean-cleaner-portable.exe` από τη σελίδα **Releases**. Τρέξε το απευθείας, χωρίς εγκατάσταση και χωρίς δικαιώματα διαχειριστή. Πάτησε **ΚΑΘΑΡΙΣΜΟΣ ΤΩΡΑ** και θα εμφανιστούν τα αρχεία και το συνολικό μέγεθος που αφαιρέθηκαν.

## Τι καθαρίζει

Μόνο συγκεκριμένους καταλόγους στον προσωπικό φάκελο `AppData\Local` του τρέχοντος χρήστη:

| Κατηγορία | Φάκελος | Ηλικία |
| --- | --- | --- |
| Παλιά προσωρινά | `Temp` | 14+ ημέρες |
| DirectX shader cache | `D3DSCache` | 14+ ημέρες |
| Crash dumps | `CrashDumps` | 30+ ημέρες |
| Windows Error Reporting archive | `Microsoft\Windows\WER\ReportArchive` | 30+ ημέρες |

Τα όρια βασίζονται στην τελευταία τροποποίηση. Διαγράφει μόνο παλιά κανονικά αρχεία, όχι φακέλους. Αποφεύγει συμβολικούς συνδέσμους και junctions. Τα κλειδωμένα/προστατευμένα αρχεία παραλείπονται.

**Δεν αγγίζει** Λήψεις, Έγγραφα, Εικόνες, Επιφάνεια εργασίας, Κάδο Ανακύκλωσης, browsers, cookies, κωδικούς, bookmarks, Registry, εφαρμογές ή ενημερώσεις Windows.

**Προσοχή:** Τα αρχεία που επιλέγονται διαγράφονται οριστικά, χωρίς Κάδο. Τα παλιά dumps ενδέχεται να χρειαστούν για τεχνική διάγνωση. Η εφαρμογή δεν υπόσχεται επιτάχυνση ούτε εγγυημένη εξοικονόμηση χώρου. Δεν αντικαθιστά το Storage Sense των Windows.

## Δημιουργία από τον κώδικα

Απαιτείται Go 1.22+· δεν υπάρχουν εξαρτήσεις τρίτων.

```powershell
go test ./...
go build -trimpath -ldflags="-s -w -H windowsgui" -o dwrean-cleaner-portable.exe .
```

Το GitHub Actions workflow κάνει αυτόματα δοκιμές και κατασκευάζει Windows .exe + ZIP. Η πρώτη επιτυχής εκτέλεση από την κύρια διακλάδωση δημοσιεύει επίσης αρχική έκδοση (Release).

Το εκτελέσιμο **δεν έχει ψηφιακή υπογραφή** και μπορεί να εμφανίσει ειδοποίηση SmartScreen. Συνιστάται δοκιμή σε πραγματικό Windows 10/11 πριν από ευρεία δημόσια διανομή.

Δεν υπάρχουν διαφημίσεις, τηλεμετρία ή πρόσβαση στο διαδίκτυο.
